# ChronosMatch: Zero-Copy High-Frequency Trading Engine

## Project Overview
ChronosMatch is a Python-based project that demonstrates the basic working of a high-frequency trading order-matching engine. It matches BUY and SELL orders based on their prices and quantities.

## Objective
The main objective is to develop an efficient order-matching system that processes buy and sell orders and executes trades when their prices are compatible.

## Technologies Used
- Python
- Visual Studio Code
- Git and GitHub

## Key Features
- Accepts BUY and SELL orders
- Matches compatible orders
- Calculates the quantity traded
- Maintains remaining unfilled orders
- Displays executed trades

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `python main.py`.
